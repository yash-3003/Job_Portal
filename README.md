# Job Role Recommendation and Placement Management System

## 📌 Project Overview

The **Job Role Recommendation and Placement Management System** is a web-based platform that leverages machine learning to predict suitable job roles for students based on their academic profiles and manages the entire placement process efficiently. Built on the robust MERN stack, it enables students, administrators, and companies to interact within a centralized system.

---

## 🚀 Features

- 🎯 **Intelligent Job Role Prediction** using ML algorithms
- 👤 **Student Portal** for managing profiles, skills, and certifications
- 🏢 **Company Dashboard** for posting jobs and viewing candidates
- 🗓️ **Placement Drive & Interview Scheduling**
- 📈 **Admin Analytics Dashboard** for placement statistics
- 🔐 **Role-based Secure Authentication** (Student, Company)

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, ShadCN
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (with Mongoose)
- **Machine Learning**: Python, Google Colab
- **Authentication**: JSON Web Tokens (JWT), bcrypt

## 📦 Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/yash-3003/Job_Portal.git
cd Job_Portal
```
### 2. Backend Installation
```bash
cd backend
npm install
# Set environment variables in a .env file (Mongo URI, JWT Secret, etc.)
npm start
npm run dev
```

### 3. Frontend
```bash
cd ../frontend
npm install
npm start
npm run dev
```

### 4. env setup
For env setup you will be required 
```bash
MONGO_URI=
PORT=8000 #optional
SECRET_KEY= #random
#cloudinary setup
CLOUD_NAME= 
API_KEY=
API_SECRET=
```
